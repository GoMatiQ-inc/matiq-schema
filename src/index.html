Table users {
  id uuid [pk]
  name varchar [not null]
}

Table posts {
  id uuid [pk]
  user_id uuid [ref: > users.id]
}
Use Table, column types, [pk], [unique], [not null], and Ref relationships. Quoted names, schemas, notes, enums and composite keys use standard DBML.
